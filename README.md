# README

Musical is an application that lets you edit the tags of audio files.

## Installation

Use the package manager [gradle](https://gradle.org/).

```bash
gradle build
```

## Configure

### add option to gradle.bat
```
DEFAULT_JVM_OPTS="-Xmx1G" "-Xms512m"
```
